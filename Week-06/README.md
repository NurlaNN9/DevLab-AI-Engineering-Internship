# Week 06 - Product Review Sentiment Classifier

This week focuses on building and comparing sentiment classification models for real customer reviews.

The required task compares a classical machine-learning baseline with a pretrained transformer model on the same train/test split.

## Task

- Build a sentiment classifier for product or service reviews
- Classify reviews as negative, neutral or positive
- Train a TF-IDF + Logistic Regression baseline
- Use a pretrained transformer model
- Evaluate both models using per-class precision, recall and F1-score
- Analyze misclassified examples
- Recommend which model should be deployed based on accuracy, latency and resource trade-offs
