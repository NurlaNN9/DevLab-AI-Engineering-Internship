# Week 03 Required Tasks

## License Plate Detection and Recognition Pipeline

The required task builds a two-stage computer vision pipeline:

1. Detect license plates with YOLOv8.
2. Crop the detected plate region.
3. Read the plate text with EasyOCR.
4. Clean the OCR output.
5. Evaluate detection with IoU.
6. Evaluate recognition with exact-match accuracy and character error rate.

See the project folder for the notebook and documentation.
